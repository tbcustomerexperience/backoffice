Conexão com o GitHub

Os dados da agenda são salvos direto no repositório, não no computador. Essas informações ficam guardadas apenas neste navegador.

É o nome do repositório no GitHub, não o link do site publicado. Encontra em github.com/<owner>/<repo>.
Se o dashboard estiver dentro de uma pasta do repositório (ex: "cronograma"), inclua a pasta no caminho. Se o arquivo ainda não existir, ele será criado automaticamente ao salvar.
Precisa de permissão de escrita em conteúdo do repositório (classic: escopo "repo"; fine-grained: "Contents: Read and write").
